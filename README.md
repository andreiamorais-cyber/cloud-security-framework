### Cloud Security Framework


## Framework prático e estruturado para estudo, adoção e implementação de Segurança em Nuvem, cobrindo governança, arquitetura, conformidade, gestão de riscos, Zero Trust e operações de segurança.

## Objetivo

Criar uma trilha completa de conhecimento que permita compreender, planejar, implementar e auditar controles de segurança em ambientes AWS, Microsoft Azure, Google Cloud e ambientes híbridos.

## Público-alvo

- Profissionais de Segurança da Informação
- Cloud Architects
- Cloud Engineers
- DevSecOps
- Auditores
- Consultores
- Gestores de Tecnologia
- Estudantes de Cloud Security
